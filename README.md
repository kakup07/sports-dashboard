# Sports Dashboard

A simple real-time sports dashboard built with **Node.js, Express, and WebSockets**.

## Features

* Real-time score updates using WebSockets
* Express server for handling HTTP requests
* Live connection between server and clients
* Simple dashboard interface

## Tech Stack

* Node.js
* Express.js
* WebSockets (`ws`)
* HTML, CSS, JavaScript

## Getting Started

Clone the project and install dependencies:

```bash
npm install
```

Start the server:

```bash
npm start
```

Open the dashboard in your browser and connect to the WebSocket server.

## Purpose

This project is mainly for learning and experimenting with **WebSockets, real-time communication, and backend development**.
